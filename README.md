# UltraCorrect 2

**В разработке.** Итерация 01a: чистое ядро механики ввода, детерминированный симулятор и каркас сборки macOS. Перехват клавиатуры, реальная вставка в приложения, интерфейс настройки и DMG появятся в 01c. Заготовки приложений сейчас не исправляют ввод.

Новый публичный репозиторий содержит только реализацию 2.x. История 0.1.x и личные данные не переносились. Основные требования: [SPEC](docs/SPEC.md), [PROCESS](docs/PROCESS.md), [ТЗ 01a](docs/iterations/01a/TZ.md).

## Проверка ядра

Нужен Swift 6.0 или новее. На macOS тесты требуют полный Xcode с завершённой первоначальной настройкой.

```sh
swift build
swift test --enable-code-coverage
swift run uc-sim --report work/uc-sim-report.json
python3 scripts/coverage.py --minimum 85
scripts/check-core-purity.sh
```

На Linux macOS-цели исключаются манифестом. CI использует официальный образ `swift:6.0.3-jammy`, `macos-latest` и `macos-15`.

## Сборка каркаса macOS

```sh
scripts/bootstrap.sh
scripts/create-signing-identity.sh
scripts/build.sh
```

Скрипт повторно использует постоянную идентичность 0.1.x. На другом Mac создаётся своя идентичность в Связке; её SHA-1 необходимо передать через `UC_SIGNING_IDENTITY` и зафиксировать в PLATFORM-NOTES. Ключ не экспортируется. Сборка без подписи предназначена для CI: `scripts/build.sh --unsigned-ci`.

Приложения создаются в `work/DerivedData/Build/Products/Debug/`, автоматически не запускаются. Системные настройки и разрешения не меняются.

## Симулятор и данные

`Tests/Scenarios/*.yaml` используют JSON-подмножество YAML 1.2: каждая запись задаёт события, профиль, модель поля, тестовые правила и ожидания. Изменения сценариев вносятся в `scripts/generate-scenarios.py`. Часы симуляции инъектируемые; задержки в сценариях — параметры модели, а не замеры производительности macOS.

Данные синтетические или взяты из ТЗ. Движок `StubLayoutEngine` получает правила как данные; настоящие словари и детектор будут в 01b. Отчёты симулятора содержат идентификаторы, счётчики и проверки, без текста поля. Таблицы физических клавиш сняты `uc-layout-dump` из четырёх установленных системных раскладок.

Воспроизводимый прогон опубликованной версии: `scripts/reproduce.sh v2.0.0-alpha.1`. Отчёт и ограничения: [итерация 01a](docs/iterations/01a/REPORT.md), [платформа](docs/PLATFORM-NOTES.md).
